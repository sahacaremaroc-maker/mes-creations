## المِصباح · La lampe · The Lamp
*De l'enfer intérieur au jardin retrouvé*, par Chahlaa Hadny (2026).

- Trois éditions : arabe (101 p.), français (101 p.), anglais (98 p.)
- Prix : 33 DH (≈ 3 €), en PDF
- Page de vente : https://claude.ai/artifact/HkwUM517DB2rQHYKstWYDj
- Couvertures et aperçus : [`maquette/misbah/`](../maquette/misbah/)

### Contenu
1. **L'enfer** : la carte de l'obscurité
2. **L'humain dans toutes ses dimensions** : corps, pensée, émotion, lien, sens, culture, conditions de vie, sacré
3. **Le chemin** : sept étapes (nommer, sécuriser, être vu, faire le deuil, le petit pas, l'intégration, le don)
4. **Le jardin possible** : cinq capacités retrouvées, une charte en douze points
5. **Guide du lecteur** : la boussole des huit dimensions, les cinq feux, un plan de 30 jours
