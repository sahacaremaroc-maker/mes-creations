# Booklets

Un booklet = un problème précis, un format court et pratique.

Structure suggérée pour chaque booklet :
1. Le problème : comment il se manifeste
2. Comprendre : d'où il vient
3. Les outils : exercices, auto-hypnose, visualisations
4. Le chemin : étapes sur quelques jours / semaines
5. Pour aller plus loin : lien avec le livre

## Modifier un booklet

1. Modifie le fichier `.md` du booklet.
2. Lance `python3 outils/construire_booklets.py` : la plateforme se met à jour.
